# ディクテオンの迷宮

女神あてなのお宝さがし ― 女神アテナと相棒のフクロウ・グラウクスが主人公の、トルネコ／シレン風ローグライク。
スマホのホーム画面に追加すると、オフラインでも遊べます。

**遊ぶ：** https://chorry00.github.io/Athena/

## スマホに入れる

一度だけ、通信できる場所で次の操作をします。2回目からは機内モードでも起動できます。

**iPhone（Safari）**
1. 上のURLを Safari で開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」
3. ホーム画面のアイコンから起動する

**Android（Chrome）**
1. 上のURLを Chrome で開く
2. 右上の︙ →「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面のアイコンから起動する

## セーブデータ

- セーブは自動で、その端末の中に保存されます。
- 別の端末や Claude 版から引っこすときは、神殿の「設定と遊び方」→「データを書き出す」で出た文字をコピーし、引っこし先の「データを読み込む」に貼りつけます。
- ホーム画面のアプリを削除すると、セーブデータも消えます。先に書き出しておいてください。

## 更新のしかた（開発用）

ゲーム本体は `game.html` です。直したあとに公開用ファイルを作りなおします。

```sh
pip install fonttools brotli pillow
python3 tools/build.py
```

`index.html`・`sw.js`・`manifest.webmanifest`・`fonts/`・`icons/` が作りなおされます。
`sw.js` の版番号が変わるので、スマホ側は次の起動時に新しい版へ切りかわります。
